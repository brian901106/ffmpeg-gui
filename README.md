# FFmpeg GUI 工具箱

一個以 Python + tkinter 開發的 FFmpeg 圖形介面工具，無需記憶指令，點幾下滑鼠即可完成常見影片處理任務。

---

## 功能

### 修正影片（縮放 + 重新編碼）
將影片重新編碼為 H.264 格式，並縮放至指定解析度。

| 參數 | 說明 | 預設值 |
|------|------|--------|
| 輸入影片 | 任意影片格式（mp4 / mov / mkv / avi …） | — |
| 輸出解析度 | 寬 × 高（像素） | 1080 × 1920 |
| CRF 品質 | 0 = 無損，51 = 最差；拉桿調整 | 18 |

對應 FFmpeg 指令：
```bash
ffmpeg -i "input.mp4" -c:v libx264 -crf 18 -vf "scale=1080:1920" -c:a copy "output.mp4"
```

---

### 加入背景音樂
將背景音樂與影片原音混合輸出。

| 參數 | 說明 | 預設值 |
|------|------|--------|
| 輸入影片 | 含音軌的影片 | — |
| 背景音樂 | mp3 / wav / aac / flac / m4a … | — |
| BGM 音量 | 0.0（靜音）~ 2.0（雙倍）；拉桿調整 | 0.3 |

對應 FFmpeg 指令：
```bash
ffmpeg -i "input.mp4" -i "bgm.mp3" \
  -filter_complex "[1:a]volume=0.3[bg];[0:a][bg]amix=inputs=2:duration=first[aout]" \
  -map 0:v -map "[aout]" -c:v copy -c:a aac -shortest "output.mp4"
```

## 安裝與執行

### 方法一：直接執行 exe（Windows）

從 [Releases](../../releases) 下載 `ffmpeg_gui.exe`，雙擊即可執行，無需安裝 Python。

> **前置需求**：需先安裝 [FFmpeg](https://ffmpeg.org/download.html) 並加入系統 PATH。

### 方法二：從原始碼執行

**需求**
- Python 3.8 以上
- FFmpeg（已加入系統 PATH）

**執行**
```bash
python ffmpeg_gui.py
```

---

## 自行打包 exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ffmpeg_gui ffmpeg_gui.py
```

產生的 `dist/ffmpeg_gui.exe` 即可單獨發佈。
